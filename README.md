# سامانه پایش، نظارت و آزمون مشاهیر دانش
## Mashahir Danesh Law School Academic Support, Supervision & Examination Platform

سامانه هوشمند، امن و یکپارچه پایش تحصیلی، آزمون‌های ارزیابی، نظارت سازمانی و هدایت علمی برای داوطلبان آزمون وکالت کانون وکلای دادگستری (اسکودا) و مرکز وکلای قوه قضائیه، پشتیبان‌های علمی، سرپرستان کوهورت و مدیریت ارشد مؤسسه حقوقی مشاهیر دانش.

---

## 🏛 معماری و فناوری‌های کلیدی (Architecture & Tech Stack)

- **فریم‌ورک وب:** Next.js 15 (App Router, React Server Components, Server Actions)
- **زبان:** TypeScript 5+ (حالت Strict - صد درصد بدون نوع `any`)
- **طراحی رابط کاربری و برندینگ:** Tailwind CSS بر پایه پالت رنگی رسمی سرمه‌ای (`#004071`)، پشتیبانی بومی از CSS Logical Properties برای چیدمان کامل راست‌چین (`dir="rtl"`), تایپوگرافی با قلم وزیرمتن (Vazirmatn)، و کامپوننت‌های بهینه‌سازی‌شده ارگونومیک
- **پایگاه داده و ORM:** PostgreSQL 16 + Drizzle ORM همراه با ایندکس‌های مرکب و ارتباطات رابطه‌ای کامل
- **انیمیشن و اسکرول سینمایی:** GSAP ScrollTrigger + Lenis Smooth Scroll جهت پیاده‌سازی تجربه Scrollytelling مراسم و تالار همایش‌های برج میلاد
- **چندرسانه‌ای و صوت:** Howler.js جهت کنترل پیشرفته جلوه‌های صوتی محیطی
- **بستر موبایل نیتیو:** Capacitor 7 برای خروجی نرم‌افزار نیتیو اندروید (Android APK)
- **مرکز تماس و پیامک:** اتصال یکپارچه به Asterisk Manager Interface (AMI) بر بستر Issabel PBX و وب‌سرویس پیامکی کاوه‌نگار (Kavenegar REST API)
- **موتور تقویم و زمان‌بندی:** انطباق با گاه‌شماری هجری شمسی (جلالی) با هفته‌های مطالعاتی شنبه تا جمعه

## 🛡 ساختار سلسله‌مراتبی و ماتریس دسترسی (Role Hierarchy & Strict RBAC)

سامانه بر اساس مدل دسترسی بدون اعتماد (Zero-Trust) طراحی شده و سطوح دسترسی سلسله‌مراتبی صریح زیر را اعمال می‌کند:

```
[ مدیرعامل / مدیر ارشد (CEO / ADMIN) ]
   │
   ├─► دسترسی کامل به گزارش‌های راهبردی و شاخص‌های کلان
   ├─► سامانه مدیریت محتوای صفحه اصلی (Landing CMS)
   ├─► نظارت سرپرستی و ممیزی ارشد
   ├─► پیکربندی درگاه‌های پیامک و VoIP
   │
[ سرپرست آموزشی (SUPERVISOR) ]
   │
   ├─► داشبورد نظارت و سرپرستی آموزشی کل کوهورت
   ├─► مدیریت و پایش پرونده‌های عارضه‌یابی و هشدارهای تحصیلی
   ├─► طراحی تمپلیت‌های برنامه مطالعاتی هفتگی
   ├─► ارجاع وظایف سازمانی به پشتیبانان
   ├─► تعریف آزمون‌های ارزیابی و تخصیص مخاطبان
   │
[ پشتیبان علمی (MENTOR) ]
   │
   ├─► پایش بحران‌های مطالعاتی داوطلبان تخصیص‌یافته
   ├─► شخصی‌سازی برنامه هفتگی برای تک‌تک داوطلبان
   ├─► تماس تلفنی از طریق خط داخلی PBX و ثبت گزارش جلسه
   ├─► ثبت راهکار آموزشی و تعیین تکلیف پرونده‌های هشدار
   │
[ داوطلب آزمون وکالت (STUDENT) ]
   │
   ├─► دسترسی اکیداً محدود به پرونده، برنامه مطالعاتی و آزمون‌های اختصاصی
   ├─► ثبت گزارش و چک‌این روزانه مطالعه و خودارزیابی جمعه
   ├─► شرکت در آزمون‌های ارزیابی زمان‌دار و دریافت کارنامه تحلیلی
   └─► ارتباط مستقیم متنی و ارسال پیوست برای پشتیبان اختصاصی
```

## 📋 نیازمندی‌های سیستم و راه‌اندازی (Prerequisites & Setup)

### پیش‌نیازها
- **Node.js:** نسخه `20.x` یا بالاتر (LTS توصیه می‌شود)
- **PostgreSQL:** نسخه `16.x`
- **npm:** نسخه `10.x` یا بالاتر

### ۱. دریافت مخزن و نصب وابستگی‌ها
```bash
git clone https://github.com/kianschool2015-ops/School-dashboard.git
cd School-dashboard
npm install
```

### ۲. پیکربندی متغیرهای محیطی
یک نسخه از فایل نمونه تنظیمات بسازید:
```bash
cp .env.example .env.local
```
فایل `.env.local` را باز کرده و اطلاعات پایگاه داده، کلیدهای ارتباطی و کلید رمزنگاری جلسات (`JWT_SECRET`) را مطابق محیط خود تنظیم فرمایید.

### ۳. راه‌اندازی پایگاه داده با Drizzle ORM
```bash
# همگام‌سازی ساختار پایگاه داده با اسکیما
npm run db:push

# (اختیاری) مقداردهی اولیه داده‌های پایه
npm run db:seed
```

### ۴. اجرای سرور توسعه (Development)
```bash
npm run dev
```
سامانه بر روی پورت `http://localhost:3000` در دسترس خواهد بود.

### ۵. ساخت بسته تولیدی (Production Build)
```bash
npm run build
npm run start
```

## 🔒 امنیت و محرمانگی (Security Guidelines)

- **متغیرهای محرمانه:** هیچ کلید API، رمز عبور یا توکن تولیدی نباید در مخزن گیت ذخیره شود. تمامی مقادیر محرمانه از طریق متغیرهای محیطی سیستم تأمین می‌گردند.
- **احراز هویت:** توکن‌های دسترسی از طریق کوکی‌های امن با پرچم‌های `HttpOnly`، `SameSite=Lax` و `Secure` در حالت پروداکشن مدیریت می‌شوند.
- **حریم خصوصی ارتباطات:** در تمامی بخش‌های نرم‌افزار، شماره‌های همراه داوطلبان به شکل ماسک‌شده (`۰۹۱۲***۰۰۰۵`) نمایش داده می‌شود تا اطلاعات شخصی داوطلبان محفوظ بماند.
